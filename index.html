1. 音声の取り込み方

方式内容特徴
会議の音声を直接取り込む
(標準)		スタート時にChromeの共有機能で、会議のタブ、または画面全体を選び、その音声を直接受け取るPCの設定・インストール不要。Windowsの音量(イヤホンの音量)に影響されない。タブ共有なら会議の音だけを拾う
音声入力デバイスから
(予備)		Windowsの既定の録音デバイス(ステレオミキサー等)の音を受け取るPCごとに設定が必要。Windowsの音量が小さいと拾いにくい。起動時に自動チェックし、未設定なら手順を表示

2. 文字起こしの仕組み(リアルタイム)

  • Chromeに組み込まれた音声認識(Web Speech API・Googleの音声認識)で、日本語の音声を文字にする
  • 話している途中の言葉は「認識中:」として青色で表示し、文が確定すると時刻付き(例:[14:05:12])で1行ずつ追加
  • 確定した文は約5秒ごとにGASへ送り、Googleドライブのテキストファイルに追記していく(途中で止まっても、それまでの分は保存済み)
  • 無音などで音声認識が止まっても自動で再開する
  • 終了ボタンで終了。1時間音声がない場合は自動で終了
  • 保存ファイル名:文字起こしを開始した日時+文字起こし(例:202611251400文字起こし)

3. 校正の仕組み(後日)

  • 文字起こしファイルを選び、Gemini(AI)で校正する
  • 校正のルール:誤変換・同音異義語・聞き間違いを文脈から修正/「えー」「あの」などのつなぎ言葉や言い直しを削除/句読点を補って読みやすく/内容の追加・削除・要約はしない/時刻はそのまま残す
  • 文字起こしを約6,000文字ずつに分け、4つずつ同時にGeminiへ送って処理する(速く、何時間の会議でも処理できる)。モデルは速くて無料枠の大きい flash-lite を優先して自動で選ぶ
  • 処理はサーバー(GAS)が裏で行う:ボタンを押すと受付だけ行い、GASが順番に処理する。画面・タブを閉じても、PCの電源を切っても処理は続く
  • 完了・エラーはメールで通知(GASを作ったGoogleアカウント宛て)。画面の「処理状況」でも進み具合を確認できる
  • Geminiが混雑している場合は、1分→3分→5分→10分…と間隔を延ばして自動で再試行(最大約2時間)。その他の失敗は1分おいて3回まで再試行
  • 無料枠はモデルごとに別々。1つのモデルが1日の上限に達したら、使える別のGeminiモデルに自動で切り替える。すべて上限の場合は、上限がリセットされる時刻(日本時間17時ごろ)に自動で再開する(受付し直す必要なし)
  • 結果はGoogleドキュメントで作成(CMなど不要な部分を自由に削除・編集できる)。保存ファイル名:日時+校正
  • 失敗した場合、途中まで作ったファイルは自動でゴミ箱へ移し、一覧に表示しない

4. 要約の仕様(後日)

  • 校正済みのファイル(Googleドキュメント)だけを選べる。編集した内容がそのまま要約に反映される。全文をGeminiに渡して要約(サーバーで裏処理し、完了をメール通知)
  • 【CM?】の印が付いた行は要約に含めない
  • 要約の構成:概要/主な議題と議論内容/決定事項/ToDo・宿題(担当者・期限が分かれば)/次回予定・その他。該当がない項目は「特になし」
  • 結果は見出し・箇条書きに整えたGoogleドキュメントとして作成
  • 保存ファイル名:日時+要約

辞書

  • 「辞書」タブで、人名・社名・専門用語などの正しい書き方を登録できる(Googleドライブの「辞書」ファイルに保存)
  • [置換](誤→正):文字起こしの保存時に自動で置き換え、校正時にもGeminiに伝える
  • [読み](読み→漢字):校正時にGeminiが文脈を見て、ひらがなや誤変換を正しい漢字に直す
  • 登録した用語は要約でも正しい表記として使われる

5. 結果の扱い

  • 3種類のファイルは、すべてGoogleドライブの「リアルタイム文字起こし」フォルダに保存。ファイル名の先頭の日時で、同じ会議のファイルがまとまる
  • 「名前付記」タブで、同じ会議の3つのファイルを、名前を付けた新しいフォルダにまとめて移動できる(移動後に校正・要約しても、結果は同じフォルダに作られる)
  • 各処理の完了時に表示されるリンクから、すぐに開ける
  • ファイル形式:文字起こし=テキストファイル/校正=Googleドキュメント/要約=Googleドキュメント
  • 校正・要約のGoogleドキュメントは、そのまま編集・共有・印刷・Word/PDFでのダウンロードができる

注意事項

  • 使えるブラウザ:パソコン版のChrome(またはEdge)。インターネット接続が必要
  • 話者(誰が話したか)は区別しない。BGMや同時発話が多いと精度が下がる
  • Gemini APIの無料枠では、送った内容がGoogleのサービス改善に使われることがある。社外秘の会議では注意
  • 専用URLにはトークン(鍵)が含まれる。他人に教えない

はじめて使うPCで

  1. ブックマークした専用URLをChromeで開く(初期設定が自動で入る)
  2. 専用URLが無い場合は「初期設定」タブで、GASのURLとトークンを入力して「保存して接続テスト」

リアルタイム文字起こし

  1. 「1: 文字起こし」タブを開く
  2. 「音声の取り込み方法」は「会議の音声を直接取り込む」のまま
  3. 「スタート」を押すと共有画面が出るので、
    • ブラウザで会議・YouTube等:「タブ」→ 対象のタブを選ぶ →「タブの音声も共有」をオン →「共有」
    • Zoom・Teamsなどのアプリ:「画面全体」を選ぶ →「システムの音声も共有」をオン →「共有」
  4. 「文字起こしモニター」に文字が出ることを確認。「入力レベル」が動いていれば音を受け取れている
  5. 終わったら「終了」(Chromeの「共有を停止」でも終了)。「保存先」のリンクからファイルを開ける

校正(後日)

  1. 「2: Geminiで校正」タブ → 文字起こしファイルを選ぶ(新しい順)
  2. 「校正」を押すと受付される。画面を閉じても処理は続く
  3. 進み具合は下の「処理状況」に表示(15秒ごとに自動更新)。完了するとメールが届く
  4. メールか「処理状況」のリンクから「日時+校正」のGoogleドキュメントを開く

要約(後日)

  1. 必要なら、校正済みのGoogleドキュメントを開いてCMなど不要な部分を削除しておく
  2. 「3: 内容を要約」タブ → 校正済みファイルを選ぶ(同じ名前が複数あるときは「更新」日時で区別)
  3. 「要約」を押すと受付される(画面を閉じても処理は続く)
  4. 完了するとメールが届く。メールか「処理状況」のリンクから「日時+要約」のGoogleドキュメントを開く

名前付記(フォルダにまとめる)

  1. 「名前付記」タブを開き、まとめる会議(日時)を選ぶ。文字起こし・校正・要約のどれがあるか表示される
  2. 新しいフォルダ名(例:2026-11-25 ISPS表彰式)を入力して「フォルダを作って移動」
  3. マイドライブ →「リアルタイム文字起こし」の中にフォルダができ、3つのファイルが移動する。移動後も校正・要約の一覧には【フォルダ名】付きで表示される

辞書の登録

  1. 「辞書」タブを開く
  2. [置換] の下に「誤→正」(例:注射状→駐車場)、[読み] の下に「読み→漢字」(例:はんだはるひさ→半田晴久)を1行ずつ書く。正しい表記だけを書いた行も可
  3. 「保存」を押す。次の文字起こし・校正・要約から使われる

困ったとき

症状対処
文字が出ない共有時に「タブの音声も共有」/「システムの音声も共有」をオンにしたか確認。対象の音(会議・動画)がミュートになっていないか確認
「共有がキャンセルされました」共有画面で「共有」を押さずに閉じた。もう一度スタート
「初期設定(URLとトークン)が未入力です」専用URLから開き直すか、「初期設定」タブで入力
「GASから正しい応答がありません」GASのデプロイのアクセスが「全員」か、URLが /exec で終わっているか確認
「トークンが一致しません」トークンを入れ直す(GASで setup を実行するとログに表示)
校正・要約で「Gemini API が混雑しています」「429」無料枠の回数制限。時間をおいて再実行
